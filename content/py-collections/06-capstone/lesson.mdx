# Capstone: the gradebook

Everything from this chapter, in one script: a dict of students to scores, averages
built with `sum`/`len`, a ranking built by sorting tuples, and a written finding.

No loops or `if` yet — those are the next chapter. That's a feature, not a limit: it
forces you to reach for Python's collection built-ins (`sum`, `len`, `max`, `sorted`),
which do the heavy lifting without a single line of control flow. You'll be surprised
how far they carry you.

This is a **sectioned** exercise: each section has its own editor and checks, and they
run top to bottom sharing one workspace — so `roster` from section 1 is still there in
section 2. Submit runs all of them; the report shows you exactly which section (if any)
needs another pass.
