# Running Python

Python runs your file top to bottom, one statement at a time. `print()` writes to the
console; a bare expression's value is simply computed and (in a script) discarded.

Unlike JavaScript there are no braces and no semicolons — **indentation is the syntax** —
and variables appear the moment you assign to them, no `let`/`const`.

Try the tasks on the right. After each run, look at the **workspace panel**: it shows every
variable that exists right now, with its type and value. Get in the habit of checking it —
it's how you see what your code *did*, not just what it printed.
