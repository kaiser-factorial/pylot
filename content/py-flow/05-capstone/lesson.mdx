# Capstone: the text-stats tool

Control flow, end to end: split text into words, tally frequencies with a loop, pull out
the interesting ones with a comprehension, and report. This is the shape of real
data-cleaning code — count, filter, summarize.

Four sections, one shared workspace. Each builds on the names before it: `words` from
section 1 is still around in section 3. Submit runs them all and shows you exactly which
section needs another pass — the whole point of a sectioned exercise.
