# Capstone: the stats tool — and explain the machine

The chapter's payoff: a small, well-structured program built from functions and composed in a
`main()`, then one final section that is the whole point of this app — **reading and
explaining code you didn't write by hand.**

Five sections, one workspace. You'll define parsing and summarizing functions, wire them
together under the `if __name__ == "__main__":` guard, and finish by explaining a dense,
AI-generated one-liner in your own words. The explanation is graded by the teacher against
what the code actually does — because the skill that matters most here isn't producing a
clever line, it's being able to say exactly what one does.
