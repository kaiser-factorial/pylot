# Capstone: the fare calculator

Functions working together: define small, self-contained helpers, give one a sensible
default, and compose them into a report. This is how real programs are built — not one
long script, but a few well-named functions you can trust and reuse.

Four sections, one workspace. A function you `def` in section 1 is callable in every later
section. Submit runs them all and reports which section (if any) needs another pass.
